# File cifrati

Questi file li scrive l'app bbb: appartamenti, proprietari e stime di guadagno, cifrati. Ogni file si apre solo
con il suo codice; il nome del file è ricavato dal codice e non dice di chi è. Il formato è descritto in
[`docs/cifratura.md`](../../docs/cifratura.md). Non modificarli a mano: un file cambiato non si apre più.
